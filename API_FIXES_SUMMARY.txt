================================================================================
TROUBLESHOOTING QUICK REFERENCE
================================================================================

Problem: "Form submission returns 404"
→ Verify /app/api/submit-form/route.ts exists
→ Check NODE_ENV isn't cached
→ Rebuild: npm run build

Problem: "Emails not being sent"
→ Check SMTP credentials in .env
→ Verify ADMIN_EMAIL is correct
→ Check spam folder
→ Review server logs: tail -f server.log

Problem: "FAQ page shows empty"
→ Run migration: psql -d grey -f migrations/004_add_faqs_table.sql
→ Check API endpoint: curl http://localhost:3000/api/faqs
→ Verify database has faq records

Problem: "Subscribe endpoint returns 500"
→ Check email validation: /^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(email)
→ Verify SMTP is configured
→ Check logs for detailed error

Problem: "Auth fails on audit GET endpoint"
→ Include header: Authorization: Bearer your-admin-token
→ Verify ADMIN_API_TOKEN is set in .env
→ Token must match exactly
