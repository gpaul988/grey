⚡ QUICK SETUP (3 steps)
═══════════════════════════════════════════════════════════════════════════

1️⃣  UPDATE ENVIRONMENT VARIABLES
    
    Edit .env.local and add:
    
    SMTP_HOST=smtp.gmail.com
    SMTP_PORT=587
    SMTP_USER=your-email@greyinfotech.com.ng
    SMTP_PASSWORD=your-app-password
    SMTP_FROM=noreply@greyinfotech.com.ng
    ADMIN_EMAIL=hello@greyinfotech.com.ng

2️⃣  RUN MIGRATION (if using PostgreSQL)
    
    psql -d grey -f migrations/004_add_faqs_table.sql

3️⃣  REBUILD & DEPLOY
    
    npm run build
    npm start
