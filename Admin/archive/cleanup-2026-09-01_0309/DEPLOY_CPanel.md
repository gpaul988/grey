cPanel deployment checklist — Grey project

1. Summary
- This app is a Next.js (app router) Node.js server (server.ts) using tsx. Production build artifacts are generated by `npm run build`. The server is started with `npm run start` (starts tsx server.ts) or `npm run cpanel:start` in package.json.

2. Server requirements
- Node 20.x (use cPanel Application Manager Node 20+).
- npm >= 10
- Writable storage for Admin/data (SQLite DB).
- If using better-sqlite3, ensure native rebuild: `npm run rebuild:sqlite` after install.

3. Files to upload / Git
- Push repository to remote (recommended). In cPanel, clone the repo into app directory or upload zip and extract.
- Ensure .env (production) exists and contains all required variables (copy from .env.example if present). Protect secrets.

4. Install & build (cPanel shell or Application Manager commands)
- cd /home/<user>/path/to/app
- npm run install:cpanel
- npm run build
- npm run bootstrap:db
- npm run seed (optional: seed data)

5. Startup configuration (Application Manager)
- Application root: repo directory
- Application startup file: server.ts (tsx will run it)
- Startup command: `cross-env NODE_ENV=production tsx server.ts` (or `npm run cpanel:start`)
- Environment: set Node version 20.x and all env vars in cPanel UI
- Process type: long-running (auto-restart)

6. Permissions
- Ensure Admin/data directory is writable by the app user (chmod 700/755 as required).
- Ensure uploads or public assets directories (if any) are writable.

7. Database & migrations
- DB path default: Admin/data/grey.db (set DB_PATH to custom path if needed)
- Run `npm run bootstrap:db` to create/migrate; if seeding run `npm run seed`.

8. SSL & domain
- Configure domain in cPanel and enable SSL (AutoSSL/Let’s Encrypt). Reverse proxy to app port if needed (Application Manager handles it).

9. Static assets & caching
- Ensure /public is served by Next.js server. Configure cache headers in server if required.

10. Post-deploy checks
- Visit /, /audit, /admin, /store; confirm HTTP 200
- Run `npm run smoke:flashsale` or internal smoke scripts if needed
- Tail logs: .next/logs or app log location to check errors

11. Rollback & maintenance
- Create backups of Admin/data/grey.db before upgrades
- Keep `pre-rollback-*` backup branch for quick git rollback

12. Common troubleshooting
- Native module errors for better-sqlite3: run `npm run rebuild:sqlite` or reinstall with matching Node
- If `next build` fails on CSS parse, inspect app/globals.css for Tailwind arbitrary selectors like `.text-[0.78em]` and remove/escape them.

13. Notes
- Remove runtime contrast-fix and broad inline-style-sweep overrides in production once source-level color fixes are applied.
- Consider using PM2 or cPanel Application Manager for process management.
