# Creating Beautiful Advertisements

## Admin Panel: `/admin/ads`

The ads system now supports **full image backgrounds** with bright, eye-catching animations and no errors.

### Creating an Ad with Images

1. **Click "New advert"** button
2. **Fill in these fields:**

   | Field | Description | Example |
   |-------|-------------|---------|
   | **Title** | Main headline | "50% Off Web Development" |
   | **Body** | Supporting text (optional) | "Limited time offer for Q3 projects" |
   | **Creative image** | Upload or paste URL | High-quality images: 1200×420px recommended |
   | **CTA label** | Button text | "Get Started", "Learn More" |
   | **CTA link** | Where button points | `https://greyinfotech.com.ng/services` |
   | **Social share caption** | Text shared to social media | "Check out our new services!" |

3. **Select options:**
   - **Variant**: "image" (for image-heavy) or "gradient" (colorful fallback)
   - **Placement**: "home_banner" (shown on homepage)
   - **Status**: "Published" (to go live immediately)
   - **Schedule**: Optional start/end dates

4. **Live Preview** shows in real-time as you type

5. **Click "Save advert"** → Appears on site instantly

## Image Best Practices

✅ **DO:**
- Use **high-contrast images** (bright, eye-catching)
- **Dimensions**: 1200×420px (or similar 3:1 aspect ratio)
- **File size**: < 500KB for fast loading
- **Formats**: JPG, PNG, WebP
- **Content**: Product shots, graphs, hero scenes, team photos

❌ **DON'T:**
- Dark/gloomy images (overlays make them hard to read)
- Text-heavy images (overlays obscure text)
- Low-resolution or blurry images
- Oversized files (slow page load)

## Image Upload Flow

### Option 1: Direct Upload
1. Click the **upload button** (📁) in the "Creative image" field
2. Select an image from your computer
3. Status shows "Uploading…" then "Uploaded ✓"
4. Preview updates automatically

### Option 2: Paste URL
1. Copy an image URL (e.g., from a CDN, Cloudinary, imgur)
2. Paste into the "Creative image" field
3. Preview updates automatically
4. Example: `https://cloudinary.com/your-image.jpg`

## Analytics & Performance

Each ad tracks:
- **Impressions**: How many times shown
- **Clicks**: How many clicked the CTA
- **CTR** (Click-Through Rate): Clicks ÷ Impressions
- **Sort order**: Change display order between ads

## Troubleshooting

| Issue | Solution |
|-------|----------|
| Image not showing | Check URL is valid (paste in browser) |
| Ad doesn't appear on site | Ensure "Published" status + "Active" checkbox |
| Text hard to read | Use brighter images or "gradient" variant instead |
| Upload fails | Try smaller file (< 500KB) or JPG format |
| Impressions not increasing | Wait a few seconds, refresh page |

## Tips for Maximum Impact

1. **Fresh images**: Update ads every 2-3 weeks for best engagement
2. **Clear headlines**: 5-8 words max for impact
3. **Strong CTA**: "Book Now" works better than "Click Here"
4. **Timing**: Schedule during peak traffic (9am-5pm weekdays)
